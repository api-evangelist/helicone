Helicone is an open-source LLM observability platform and AI gateway that helps developers monitor, evaluate, and experiment with their AI applications. The worlds fastest-growing AI companies rely on Helicone to route, debug, and analyze their applications.

**Areas:** AI Gateway · AI Monitoring · Gateways · LLM Observability · LLM Routing · Prompt Management

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Helicone: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
