### Helicone AI Gateway API

The Helicone AI Gateway API provides OpenAI-compatible endpoints for routing requests to 100+ AI models across providers including OpenAI, Anthropic, Google, Groq, and more. It offers a unified API with automatic provider fallbacks, zero markup pricing, built-in observability, intelligent routing, prompt caching, error handling, and image generation support.

- **Human URL:** [https://docs.helicone.ai/gateway/overview](https://docs.helicone.ai/gateway/overview)
